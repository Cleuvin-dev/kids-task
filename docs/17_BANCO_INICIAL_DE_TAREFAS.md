# 17 — Banco Inicial de Tarefas

## 1. Finalidade

Fornecer modelos editáveis. O responsável decide se uma tarefa é adequada à criança. Textos não substituem supervisão adulta.

Cada template contém:

- título;
- ícone;
- faixa sugerida;
- categoria;
- período sugerido;
- orientação curta;
- aviso de supervisão, quando necessário.

## 5. Tarefas bônus de fim de semana

- ajudar a lavar o carro;
- organizar uma gaveta;
- ajudar a preparar uma receita;
- cuidar do jardim;
- separar itens para doação;
- organizar jogos da família;
- ajudar em uma pequena atividade doméstica;
- concluir um desafio de leitura;
- preparar um passeio com checklist;
- ajudar a organizar compras.

## 6. Segurança de conteúdo

- tarefas com cozinha, produtos de limpeza, animais ou áreas externas devem sinalizar supervisão;
- não sugerir tarefa incompatível com a idade;
- não criar tarefa humilhante ou perigosa;
- o responsável pode editar, mas a plataforma deve bloquear termos claramente abusivos em fase futura;
- KidsCoins reforçam comportamento, não substituem cuidado ou diálogo.

## 7. Seeds

Templates globais ficam separados das tarefas familiares:

- `task_templates` é somente leitura para famílias;
- criar a partir de template copia os campos;
- editar uma tarefa familiar não muda o template;
- templates possuem versão, faixa e locale;
- painel de conteúdo publica novos templates.
